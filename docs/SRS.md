## 1. 서론

### 1.1 목적
이 문서는 I-Study 시스템의 소프트웨어 요구사항을 정의합니다.  
IEEE 830 기반 SRS 구조를 따르며, 현재 구현된 코드와의 매핑을 포함합니다.

### 1.2 범위
- **시스템명**: I-Study (스마트 학습 도우미)
- **목표**: AI 머리 방향 추적 및 URL 모니터링을 통한 학습 집중도 실시간 관리
- **대상 사용자**: 온라인 학습자 (주로 수능 준비 학생)
- **플랫폼**: Windows 10/11 데스크톱

### 1.3 용어 정의

| 용어 | 정의 |
|------|------|
| 머리 방향 추적 (Head Pose Tracking) | 카메라를 통해 사용자의 머리 방향을 실시간 분석 |
| 화이트리스트 | 학습 중 접속을 허용하는 사이트 목록 |
| 이탈 감지 | 사용자가 화면 중앙에서 벗어나거나 얼굴이 미감지된 상태 |
| 눈 감음 | 양쪽 눈이 닫힌 상태가 임계 시간 이상 지속 |
| 캘리브레이션 | 사용자 개인별 시선 기준점 보정 |
| 집중 모드 | 머리 방향 추적 + URL 모니터링이 활성화된 학습 상태 |
| 데몬 스레드 | 메인 앱 종료 시 자동으로 함께 종료되는 백그라운드 스레드 |

### 1.4 참조 문서
- `docs/ARCHITECTURE.md` — 소프트웨어 아키텍처
- `docs/FEATURES.md` — 기능 구현 명세서

- `docs/SYSTEM_DIAGRAM.md` — 시스템 구성도

## 3. 기능 요구사항

### FR-001: 머리 방향 추적
| 항목 | 내용 |
|------|------|
| **ID** | FR-001 |
| **이름** | 실시간 머리 방향 추적 |
| **우선순위** | 필수 |
| **설명** | 카메라를 통해 사용자의 시선 방향을 실시간으로 추적한다 |
| **입력** | 카메라 프레임 (640×480, 30fps) |
| **처리** | MediaPipe 얼굴 감지 → 478개 랜드마크 → 시선 방향 계산 |
| **출력** | 시선 방향 (center/left/right/up/down/no_face) |
| **수락 기준** | - 30fps 이상 처리 속도 유지<br>- 5방향 + 얼굴 미감지 판별<br>- 정면 기준 좌우 20%, 상하 38% 범위 내 center 판정 |
| **구현 파일** | `core/head_pose_tracker.py` |
| **구현 상태** | ✅ 완료 |

## 4. 비기능 요구사항

| 항목 | 요구사항 | 현재 달성 |

| 메모리 사용량 | < 300MB | ✅ ~250MB |
| CPU 사용률 | < 30% | ✅ ~15% (스레드 분산) |

## 7. 데이터 요구사항

### 7.1 데이터 모델

```
┌─────────────────┐     ┌──────────────┐
│ whitelist_urls   │     │  study_log   │
├─────────────────┤     ├──────────────┤
│ id (PK)         │     │ id (PK)      │
│ name (TEXT)     │     │ study_date   │
│ url (UNIQUE)    │     │ start_time   │
│ created_at      │     │ end_time     │
└─────────────────┘     │ total_time_s │
                        │ focus_time_s │
                        │ created_at   │
                        └──────────────┘
```

### 7.2 데이터 보존

| 데이터 | 보존 기간 | 크기 예측 |
|--------|-----------|-----------|
| 화이트리스트 | 영구 | ~1KB (수십 개) |
| 학습 기록 | 영구 | ~10KB/월 (일 3회 기준) |
| 로그 파일 | 순환 (5MB × 3) | 최대 15MB/로거 |

### 7.3 데이터 무결성

- URL 중복 방지: `UNIQUE` 제약
- 학습 기록 필수값: `NOT NULL` 제약
- 파라미터 바인딩: SQL Injection 방지
