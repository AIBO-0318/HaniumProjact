# I-Study 고개 방향 인식률 테스트 도구

메인 앱(GazeTracker)과 동일한 알고리즘으로 고개 방향(상/하/좌/우) 인식률을 측정하는 독립 실행 도구입니다.

## 설치

### 1. Python 3.8 이상 필요

### 2. 의존성 설치
```bash
pip install -r requirements.txt
```

**설치 시간**: 약 2~3분 (처음 실행 시 MediaPipe 모델 자동 다운로드)

## 실행

```bash
python test_head_pose.py
```

## 사용 방법

### 1단계: 캘리브레이션
- **정면을 응시**한 상태에서 **`C`키를 10번** 누르세요
- 정면 기준 비율이 보정됩니다

### 2단계: 방향별 테스트
| 키 | 방향 | 동작 |
|:--:|------|------|
| `1` | 정면 (Center) | 정면 응시 → 5초간 인식률 측정 |
| `2` | 왼쪽 (Left) | 왼쪽으로 고개 → 5초간 측정 |
| `3` | 오른쪽 (Right) | 오른쪽으로 고개 → 5초간 측정 |
| `4` | 위 (Up) | 위로 고개 → 5초간 측정 |
| `5` | 아래 (Down) | 아래로 고개 → 5초간 측정 |

### 3단계: 결과 확인
- **`R`** → 콘솔에 방향별 인식률(%) 리포트 출력
- **`Q`/`ESC`** → 종료 + 최종 리포트

## 화면 표시 정보

- **좌측 상단**: H/V 비율 + 임계값 범위
- **좌측 중앙**: 눈 상태 (OPEN/CLOSED)
- **좌측 중앙**: 현재 감지 방향
- **비율 바**: 좌우/상하 비율 시각화 (빨간 선 = 임계값)
- **우측 상단**: 방향별 테스트 결과 퍼센티지
- **하단**: 테스트 진행 상황 (남은 시간, 정답/전체)

## 기술 사항

- **AI 모델**: MediaPipe Face Landmarker (478개 얼굴 랜드마크)
- **알고리즘**: 코 위치 비율 기반 (solvePnP 미사용)
- **임계값** (기본값):
  - 좌우: Left < 0.20, Right > 0.80
  - 상하: Up < 0.38, Down > 0.62
  - 캘리브레이션 후 margin ±0.15/0.12로 자동 조정

## 문제 해결

### 카메라가 인식되지 않음
```bash
# Windows: 카메라 권한 확인
# macOS: 시스템 환경설정 → 보안 및 개인정보 보호 → 카메라
# Linux: sudo usermod -a -G video $USER
```

### 모델 다운로드 실패
- 인터넷 연결 확인
- 방화벽/프록시 설정 확인

  - 다운로드 후 `face_landmarker.task`를 이 폴더에 저장
